Persistent View Transitions Architecture

All portal workspaces enforce persistent sidebar positioning and instant, blink-free navigation across pages via the View Transitions API and hover prefetching:

  • Hardcoded Static DOM: The complete <aside id="sidebar-menu" class="sidebar sidebar-frame"> is pre-rendered in all portal HTML templates, preventing post-load layout shifts.
  • View Transition Tag: view-transition-name: portal-sidebar; instructs Chromium browsers to anchor the sidebar in place during cross-page crossfades.
  • Hover Prefetch: Navigation scripts listen for mouseenter on links and inject <link rel="prefetch"> for instantaneous page responses.
  • Semantic Active State: The current page is marked with .nav-btn-active and aria-current="page", featuring primary terracotta background (#D97251) and bold black text (#000000).

Modal Keyboard & Accessibility Contract

  • Escape Key Dismissal: Pressing Esc immediately closes the active modal overlay without submitting data.
  • Backdrop Click to Close: Clicking the dimmed overlay outside the .modal-container safely dismisses the modal.
  • Auto-focus & Trap: Opening shifts focus into the first input or textarea; closing returns focus to the triggering button.
  • Validation & Error Feedback: Required rejection reasons trigger immediate warning toasts before modal confirmation can proceed.
